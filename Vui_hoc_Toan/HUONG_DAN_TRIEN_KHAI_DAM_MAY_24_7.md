## 🌟 CÁCH KÍCH HOẠT VERCEL (CHỈ MẤT 2 PHÚT - KHUYÊN DÙNG SỐ 1)

### Bước 1: Đăng nhập vào Vercel bằng GitHub
1. Mở trình duyệt và truy cập: **[https://vercel.com/signup](https://vercel.com/signup)**
2. Chọn **"Continue with GitHub"** và đăng nhập bằng tài khoản GitHub của bạn (`hungdz22072014`).

### Bước 2: Nhập dự án từ GitHub
1. Trên màn hình Vercel, bấm nút **"Add New..."** -> chọn **"Project"**.
2. Tìm và chọn repository: **`demo-manhhung`** rồi bấm nút **"Import"**.

### Bước 3: Cấu hình thư mục và API Key (Rất quan trọng)
1. **Root Directory**:
   - Bấm nút **"Edit"** bên cạnh mục `Root Directory`.
   - Chọn hoặc gõ: **`Vui_hoc_Toan`** rồi bấm **Continue**.
2. **Environment Variables (Biến môi trường bảo mật)**:
   - Mở mục **Environment Variables**.
   - Key: `GEMINI_API_KEY`
   - Value: Mở file `key.txt` trên máy bạn, copy mã API Key và dán vào đây.
   - Bấm **Add**.

### Bước 4: Hoàn tất
- Bấm nút **"Deploy"**.
- Chờ khoảng 30 giây, Vercel sẽ cấp ngay cho bạn một đường link cố định trọn đời dạng:
  👉 **`https://vui-hoc-toan-xxx.vercel.app`**
- Bạn có thể vào phần **Settings -> Domains** trên Vercel để đổi tên link thành bất kỳ tên nào bạn muốn (ví dụ: `vuihoctoan-thcs.vercel.app`).
